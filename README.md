# NWpacd Vocabulary

A simple web-based vocabulary learning application developed as a group project for the **Python 2** course.

## About the Project

**NWpacd Vocabulary** is an educational project created by a team of three students as part of the Python 2 course.

The main objectives of this project are to:

- Apply Python programming knowledge to a practical project.
- Explore AI-assisted software development.
- Learn the basics of Git and GitHub for version control and collaboration.
- Gain hands-on experience in building a web application.

This project is intended for learning and experimentation rather than commercial use.

## Features

- User registration and login.
- Personal vocabulary management.
- Organizing vocabulary by language.
- Adding, editing, deleting, and searching vocabulary.
- Reviewing vocabulary with flashcards.
- Basic user administration.

## Technologies Used

- **Python** — application logic.
- **Flask** — web framework.
- **Flask-SQLAlchemy** — database interaction.
- **SQLite** — data storage.
- **HTML, CSS, and JavaScript** — user interface and interactions.
- **Git and GitHub** — version control and project collaboration.
- **AI tools** — assistance with code generation, debugging, and development.

## Getting Started

### Prerequisites

- Python 3
- pip
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/mangochest/NWpacd-Vocabulary.git
cd NWpacd-Vocabulary
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

On Windows:

```bash
.venv\Scripts\activate
```

On macOS/Linux:

```bash
source .venv/bin/activate
```

Install the required dependencies:

```bash
pip install flask flask-sqlalchemy
```

Run the application:

```bash
python app.py
```

Open `http://127.0.0.1:5000` in your browser.

*Note: These instructions assume the application uses the dependencies listed above. Additional dependencies may be required depending on the current implementation.*
